# 官方服务说明

SecAgent 官方中转服务为桌面端与 CLI 提供统一的模型接入：登录 SECTL 账号即可使用 DeepSeek、Doubao、Qwen、GLM、Gemini、Step、GPT 等多个上游模型，无需自行申请各家 API Key。

服务使用 **Points（积分）** 计费，本页说明计费规则、模型价格与免费额度。

不想使用官方服务时，也可以接入自己的模型服务，客户端支持的协议见[自定义服务提供商](/guide/custom-providers)。

## Points 体系

- **10 Points = 1 元人民币**，余额、充值、扣费均以 Points 为单位
- 每次模型调用完成后，按实际输入 / 输出 Token 数量立即从余额中扣除
- 余额不足时请求会被拒绝，不会产生部分扣费或欠费
- 付费模型在调用前会预检余额，余额为 0 时直接拒绝；免费模型不受限制

## 获取 Points

新注册账号初始余额为 0，可通过以下方式充值：

- **兑换码**：在客户端输入兑换码自助充值，适合活动发放与批量分发
- **管理员充值**：由管理员在后台为指定账号充值

兑换码可限制总兑换次数，每位用户对同一兑换码只能兑换一次；兑换得到的额度可以是永久有效、固定日期过期或兑换后 N 天过期。

### DeepSeek V4 Flash 峰谷时段

高峰时段为北京时间 `09:00–12:00`、`14:00–18:00`，其间输入 30 / 输出 90 Points/1M；其余时段输入 20 / 输出 50。缓存命中输入不单独优惠，按普通输入计费。

**非高峰示例**：输入 1,000 Token + 输出 500 Token = 0.045 Points（约 ¥0.0045）。

| ≤ 32K | 2 / 20 | 2.2 / 8.8 |

| 32K–256K | — | 6.6 / 26.4 |

::: warning 注意
分档依据是**单次请求**的输入长度，不是账户累计用量。上下文越长（历史消息越多），单次请求可能落入更高价档位。

### 缓存命中优惠

GLM-4.7 FlashX 支持缓存命中（Cache Read）：命中缓存的输入 Token 按 **1 Points/1M**（输入价 5 的 1/5）计费。同一会话连续对话时输入高度重复，可显著降低成本。

**示例**：输入 1,000 Token（600 命中缓存）+ 输出 500 Token = 0.0176 Points（约 ¥0.0018）。

### 按实际成本结算

GPT 5.6 Luna 按上游实际成本结算：调用后按本次请求的真实消耗扣费（**成本价、无加价**）。仅在无法精确核算时按回退单价（输入 0.2 / 输出 1.2 Points/1M）计费。

## 虚拟档位

客户端中的「快速」「低延迟」「标准」「深度」是虚拟档位，由中转服务按路由策略自动解析到一个当前可用的实际模型：

| 档位 | 路由策略 | 思考强度 |
|---|---|---|
| 快速 | 按优先级取第一个可用模型 | 不思考 |
| 低延迟 | 取最近一次检测中首 Token 延迟最低的模型 | 不思考 |
| 标准 | 按优先级取最低档，不可用逐级向上回退 | 低 |
| 深度 | 按优先级取中档，不可用时向两侧扩展回退 | 中 |

- **按实际路由到的模型价格计费**，虚拟档位本身不额外加价
- 路由参考上游健康状态、首 Token 延迟与吞吐，异常或过慢的上游自动跳过
- 优先级顺序由服务端动态调整，无需更新客户端

## 免费额度

以下功能**不消耗 Points**：

- **免费模型**：GLM-4.7 Flash、Step 3.5 Flash、Step 3.7 Flash，输入输出均 0 Points。免费模型访问量大时可能间歇性限流（请求失败不扣费，稍后重试即可）
- **中文语音识别**：桌面端麦克风使用的云端流式识别免费，每用户每日上限 **8 小时**（按识别音频时长累计），同一账号同时仅允许一个识别连接

## 计费规则要点

- **失败不扣费**：模型请求失败（上游错误、超时等）不产生扣费
- **状态监测不扣费**：系统自动的上游健康检查与速度测试不计入用户消费
- **计费时点**：流式请求在响应完成后按实际 Token 结算；非流式请求在响应返回时结算
- **模型动态上下线**：上游异常的模型会临时从模型列表中隐藏，恢复后自动重新出现

## 查看余额与用量

桌面端登录 SECTL 账号后，可在账户信息中直接查看当前 Points 余额。

余额可能由多个额度分组组成（例如活动兑换的限时额度 + 永久额度）：

- 使用时**优先消耗最快失效的额度**，让永久额度留到最后
- 过期额度自动失效，不再计入余额
- 兑换码到账后立即生效，可在账户信息中查看到账明细
